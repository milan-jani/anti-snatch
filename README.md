# Anti-Snatch

Anti-Snatch is an offline Android security application designed to protect your device from physical theft (like snatching). 

## Features
- **100% Offline**: Operates completely on your device using built-in sensors. No internet connection or external API keys are required.
- **Sensor Telemetry**: Monitors real-time linear acceleration and angular velocity.
- **Auto-Lock Mechanism**: Automatically locks your device screen if sudden movement indicative of snatching is detected.
- **Dynamic UI**: Features a premium dark mode UI with a responsive safety gauge that shifts from green to red based on movement intensity.

## Privacy & Security
This app does not transmit any of your sensor data to the cloud. All computations and lock mechanisms are handled locally on the device for maximum privacy and rapid response.
